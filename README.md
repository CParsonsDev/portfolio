# Angular Portfolio

## Overview

This portfolio is built with Angular to represent my experience in software and product development.

Currently, this project is in early development as a working prototype.

I intend to include more exciting projects as they are developed, and provide a better overall user experience.

### Objective

I want to work with people to help them with their projects! I want this portfolio app to convince people that I'm a fun professional that does good work, and understand how they can get ahold of me if they're interested in what I can do for them.

## Martket Research

### Competitors

Structure: easily navigable, lean, typically single-column w/ cards
Styling: stylish, animated, 1-2 accent colors, uniform
Content: mixed static & dynamic, focused, mostly personal projects

### Audience

Prospective partners and employers typically spend little time on portfolio sites. As with other consumers, aim to convey information as quickly and clearly as possible.

Do not oversell achievements. Make the work speak for itself.

## Design & Requirements

### Design

The portfolio follows a 4-hue color scheme, each with 4 shades. The colors are blue, green, brown, and gray which are inspired by the scenic Pacific Northwest to convey a calm, professional tone.

The app is navigated like a knowledge base with categorized articles - each containing work samples. There is also a blog-style landing page to demonstrate a professional and engaging face to the portfolio that users will be familiar with.

Styling throughout the portfolio will feel cohesive and consistent. The site should be responsive to user light/dark preferences and screen dimensions.

The portfolio will be engaging with animations and gamified elements.

### Requirements

+ Included documents and applications:
  + Maintain functionality while included in the portfolio
  + Are viewable within the app without download
  + Can be downloaded through the app
  + Are provided with links to view source code

+ Descriptions are provided for each project included in the portfolio explaining:
  + Functionalities
  + Intended users
  + Tools and languages used

+ Navigation:
  + Is intuitive
  + Guides users to their destination within three clicks

+ The app engages users with:
  + Sleek animations
  + Gamified elements
  + Providing opportunities to give feedback through the app
  + Responsiveness, such as:
    + Light/dark toggling
    + Screen dimension responsiveness
    + Color pallete selection
    + Mobile view on desktop
